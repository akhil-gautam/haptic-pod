# Haptic Pod v1 — plan (by Fable 5.2)

Native iOS click-wheel music player. The whole phone screen is the device: silver body, black display on top, black wheel below. Button feel comes from Core Haptics.

## Decisions
- iOS 18.0+, Swift 6, SwiftUI, iPhone only, portrait. No third-party deps. Project generated by xcodegen (`project.yml`).
- Explicit `@MainActor` on UI/state objects; background work in nonisolated static async functions returning Sendable values.
- Playback: `AVAudioPlayer`, one per track (local files only, simple seek, FLAC decode). Background audio, lock-screen controls via `MPNowPlayingInfoCenter` + `MPRemoteCommandCenter`.
- Music source: files downloaded from Google Drive into the Files app. Import via `.fileImporter` (files and folders, security-scoped, `NSFileCoordinator` so Drive materialises files) into `Documents/Music`. `UIFileSharingEnabled` + `LSSupportsOpeningDocumentsInPlace` expose the folder in Files. Rescan on launch / foreground / after import.
- Playlists are automatic: "Recently Added" (50 newest) + one playlist per imported folder.
- Lists are windowed (no ScrollView); each nav frame stores `selection` and `top`; only the wheel moves the selection. Tapping a row on screen also selects it.
- Wheel: 18° per detent (20 per turn) with a haptic tick; fast spin multiplies on long lists. Centre = select, HOME = back (hold = root), ⏮/⏭ = prev/next (hold = seek ±5 s), ⏯ = play/pause.
- Now Playing: wheel scrubs (2 s per detent), seek commits on finger-up; centre = play/pause.
- Settings: HAPTICS OFF/LOW/MED/HIGH, CLICK SOUND, SHUFFLE, REPEAT, IMPORT MUSIC, RESCAN, ABOUT.

## Haptic vocabulary (transient events, intensity × user level)
| Kind | Intensity | Sharpness | Use |
|---|---|---|---|
| tick | 0.55 | 0.90 | detent |
| tickSoft | 0.38 | 0.95 | detent while spinning fast |
| pressDown | 1.00 | 0.55 | button click |
| pressUp | 0.55 | 0.80 | centre release |
| home | 0.90 | 0.30 | back / menu |
| thud | 0.70 | 0.10 | list boundary / nothing to do |
| double | 0.8 then 1.0 @ 90 ms | 0.60 | long-press confirm |

Engine: `playsHapticsOnly`, auto-shutdown off, pre-built pattern players, restart after stop/reset, UIKit feedback-generator fallback.

## Architecture
```
HapticPod/
  App/HapticPodApp.swift          @main, builds services, scenePhase handling
  Models/Track.swift              Track, Paths, time formatting
  Models/Screen.swift             Screen, NavFrame, MenuItem, SettingItem, GroupInfo, ListContent
  Library/LibraryStore.swift      tracks + derived artists/albums/playlists, index JSON
  Library/LibraryScanner.swift    enumerate Documents, diff, concurrent metadata reads
  Library/MetadataReader.swift    AVURLAsset → title/artist/album/duration/artwork
  Library/ArtworkCache.swift      thumbnail/full JPEGs in Caches + NSCache
  Library/MusicImporter.swift     security-scoped copy into Documents/Music
  Playback/PlayerService.swift    queue, AVAudioPlayer, session, interruptions
  Playback/NowPlayingBridge.swift remote commands + artwork (nonisolated closures)
  Haptics/Haptics.swift           Core Haptics engine + fallback
  Navigation/Navigator.swift      nav stack, wheel routing, actions
  Views/…                         DeviceView, WheelView, WheelGestureModel, DisplayView, StatusBarView,
                                  HomeMenuView, ListScreenView, Rows, NowPlayingView, ArtworkView, Theme
```

## Risks
1. Swift 6 isolation: MediaPlayer / Core Haptics / AVAudioPlayer callbacks arrive off-main — closures built in nonisolated context, hop with `Task { @MainActor in }`.
2. Haptic latency — keep engine running in foreground, pre-create players.
3. Angle noise near wheel centre — ignore movement inside 12% radius.
4. Bottom-edge system gesture — `defersSystemGestures(on: .bottom)`, wheel kept well above the edge.
5. Undownloaded Drive files — coordinate reads.
6. FLAC metadata may be missing — fall back to `.metadata` then filename parsing.
7. Free/personal signing: trust the developer cert on the phone (Settings › General › VPN & Device Management), Developer Mode on.
8. No "iPod" in user-facing strings.

## Build & install
```bash
xcodegen generate
xcodebuild -project HapticPod.xcodeproj -scheme HapticPod -configuration Debug \
  -destination 'generic/platform=iOS' -derivedDataPath build -allowProvisioningUpdates build
xcrun devicectl device install app --device <UDID> build/Build/Products/Debug-iphoneos/HapticPod.app
xcrun devicectl device process launch --device <UDID> com.akhilgautam.hapticpod
```
