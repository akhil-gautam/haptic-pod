# App Icon (Detents) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Haptic Pod its Detents app icon (light, dark and tinted) and a README logo.

**Architecture:**
- One Swift script draws every icon PNG and both logo SVGs with CoreGraphics, using the spec's
  geometry.
- An asset catalogue carries the PNGs.
- `project.yml` wires the catalogue in.

**Tech Stack:** Swift script (CoreGraphics, ImageIO), Xcode asset catalogue, xcodegen.

**Spec:** `docs/superpowers/specs/2026-11-20-app-icon-design.md`

## Global Constraints

- **Colours:** only #000000 and #FFFFFF, plus transparency.
- **Geometry, on a 1024 canvas:**
  - Short ticks: r 205–248, stroke 21.
  - Long tick: r 150–325, stroke 34.
  - Round caps.
  - 23 short ticks every 15°, none at 12 o'clock.
- **Small sizes (≤ 87 px):** 12 short ticks every 30° (none at 12 o'clock), strokes ×1.4.
- **No third-party tools;** none are installed.
- **Git:** no commits until the user has tested on the phone.

## Review Focus

- **Light icon:** it has a black background and is fully opaque, since iOS rejects icons with
  alpha.
- **Dark and tinted icons:** they have transparent backgrounds with white ticks only.
- **Sizes:** each small size really uses the 12-tick drawing, and actool reports no
  missing-size or unassigned warnings.

### Task 1: Icon generator

**Files:**
- Create: `scripts/make_icon.swift`. Run it as `swift scripts/make_icon.swift`; it writes to
  fixed paths under the repo root.

**Interfaces:**
- Produces:
  - `HapticPod/Assets.xcassets/AppIcon.appiconset/` with `Contents.json` and
    `icon-<px>[-dark|-tinted].png`.
  - `docs/logo.svg` (black ticks) and `docs/logo-dark.svg` (white ticks), both on a transparent
    background.

- [ ] **Step 1:** Write `drawMark(ctx:size:background:ticks:)`.
  - It scales the 1024 geometry to the given size.
  - Ticks are 12 when px ≤ 87, otherwise 24 minus the 12 o'clock tick.
- [ ] **Step 2:** Write the `Contents.json` entries:
  - Every iOS "All Sizes" slot: 20/29/38/40/60/64 at 2x and 3x, 68/76/83.5 at 2x, and 1024 at 1x.
  - Each slot in three appearances: any, dark and tinted.
- [ ] **Step 3:** Write the SVG logos from the same numbers.
- [ ] **Step 4:** Run the script.
  - Expected: 48 PNGs and 2 SVGs.
  - `sips -g hasAlpha` on `icon-1024.png` reports `no`.
  - The 60 px PNG visibly has 12 ticks, and the 1024 px one 23 plus the long tick.

### Task 2: Wire in and verify

**Files:**
- Modify: `project.yml`. The catalogue sits under `HapticPod/`, so it's already a source. Add
  `ASSETCATALOG_COMPILER_APPICON_NAME: AppIcon` to the target settings.
- Modify: `README.md`. Add a `<picture>` logo above the title.

- [ ] **Step 1:** `xcodegen generate`, then build.
  - Expected: BUILD SUCCEEDED, and no AppIcon warnings in the actool output.
  - `Assets.car` and `AppIcon60x60@2x.png` are in the .app.
- [ ] **Step 2:** Install on the iPhone and check the home screen in light, dark and tinted modes.
  This is the user's check on the phone.
